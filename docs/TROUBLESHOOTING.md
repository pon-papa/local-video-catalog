# うまくいかないとき

症状から探してください。多くは**環境チェックの画面に対処が書かれています**。

---

## 起動できない

### Start.cmd を押しても何も起きない

黒い画面が一瞬出て消える場合、起動の失敗が記録されています。

```
userdata\logs\startup-error_*.log
```

を開いてください。原因が書かれています。

よくある原因:

- ZIP を**展開せずに**そのまま実行している → 必ず展開してください
- 書き込みできない場所に置いている → `Program Files` の下などは避けてください
- ウイルス対策ソフトが `runtime\pythonw.exe` を止めている

### 「アプリ構成が壊れています」と出る

ZIP の展開が途中で終わっているか、フォルダーの一部が消えています。

`app-root.marker` `Start.cmd` `launch.py` `src\` `runtime\` が
すべて揃っているか確認し、揃っていなければ ZIP から展開し直してください。

**`userdata\` は消さないでください。** 解析結果が入っています。

## 環境チェックで ✕ が出る

### ffmpeg が見つからない / ffprobe が見つからない

動画の情報を読み、代表画像を取り出すのに必要です。

<https://ffmpeg.org/download.html> から Windows 向けのビルドを入手し、
「参照」から `ffmpeg.exe` / `ffprobe.exe` の場所を指定してください。

### whisper 機能を利用できません

お使いの ffmpeg に文字起こしの機能が入っていません。

- 文字起こしを使いたい → `whisper` フィルターを含むビルド（8.x 以降のフル版）に替えます
- 使わなくてよい → **「文字起こしを飛ばす」にチェック**を入れれば、そのまま進められます

### ローカルAIに接続できません

LM Studio が起動していないか、Local Server が OFF です。

1. LM Studio を起動する
2. モデルを読み込む
3. **Local Server を ON** にする（既定 `http://127.0.0.1:1234`）
4. 「環境チェック」を押し直す

### 映像解析に使用するローカルAIモデルが選択されていません

「今回の実行条件」の **「設定…」** を押し、映像の解析に使うモデルを選びます。

一覧には LM Studio が実際に返したモデルだけが出ます。
何も出ないときは、LM Studio 側でモデルを読み込んでから「モデル一覧を再読込」を押してください。

### 前回使用したモデルを利用できません

前に選んだモデルが、いまの LM Studio にありません。

**別のモデルへ勝手に切り替えることはしません。**
「設定…」から選び直してください。

### このモデルでは画像入力を利用できません

選んだモデルが画像を受け取れませんでした。映像の解析には
画像を扱えるモデル（VLM）が必要です。別のモデルを選んでください。

動作を確認しているのは `qwen3-vl-8b-instruct` です。

> モデル名に `VL` や `Vision` が入っていても、実際には画像を扱えないことが
> あります。このアプリは名前ではなく、**実際に小さなテスト画像を 1 枚送って**
> 確かめています。

### 画像処理能力を確認できませんでした

時間内に返事がありませんでした。多くは、LM Studio がモデルを
読み込んでいる最中です。

少し待ってから **「環境チェック」** を押し直してください。
確認できないまま解析を始めると、すべての動画が失敗して時間を
無駄にするため、安全のため開始できないようにしています。

### 文字起こしに使うモデルがありません

`userdata\models\whisper\` に `ggml-*.bin` を置いてください。
文字起こしを使わないなら「文字起こしを飛ばす」で進められます。

## 対象の動画について

### 「このフォルダーには動画が見つかりませんでした」と出る

- 指定したフォルダーが違っている
- 動画がサブフォルダーの中にある → **「サブフォルダーも含める」** にチェック

### 「解析候補」の数が思ったより少ない

すでに解析が終わった動画は候補に入りません。
残っているのは「まだ終わっていない動画」だけです。

### 一覧に「ほか N 本」と出る

本数を制限していないとき、対象が多いと先頭 10 本だけ表示します。
処理そのものは台帳ID順に続きます。表示を省いているだけです。

## 実行中・実行後

### 途中で止めたい

**「安全停止」** を押します。すぐには止まりません。
区切りのよいところまで進んでから止まります（**この間に電源を切らないでください**）。

止まったあと、もう一度「処理開始」を押すと**続きから**始まります。

### 「稼働時間に達したため、区切りのよいところで停止しました」

指定した稼働時間を使い切りました。異常ではありません。
そこまでの成果は保存されています。もう一度「処理開始」で続きから進みます。

### 「途中まで処理 : 1 本」と出た

止めた時点で、その動画の工程が途中だったという意味です。
**失敗ではありません。** 次回はその続きから始まります。

例: 文字起こしが 17 個中 16 個まで終わっていた場合、次回は残り 1 個だけ処理します。

### 「失敗 : n 件」と出た

こちらは本当にうまくいかなかったものです。ログに理由が出ています。
**「失敗のみ再試行」** で、その動画だけやり直せます。

### 同じエラーが 3 本続いて止まった

LM Studio が落ちているなど、環境側の問題が続いていると判断して止めています。
原因を直してから、もう一度「処理開始」を押してください。

## 中間ファイルの整理（cleanup）

### 何をするもの?

解析の途中で作った作業用ファイル（代表画像・解析結果のキャッシュなど）を
**Windows のゴミ箱へ移動**します。完全削除はしません。

「完了した動画の中間ファイルをゴミ箱へ移動する」にチェックを入れて実行すると、
**今回終わった分だけでなく、以前このチェックを外して処理した動画**の分も
まとめて整理します。何度実行しても安全です。

### 消えないもの

次は整理の対象外です。

- 元の動画（そもそも読むだけで、変更も削除もしません）
- 台帳（データベース）
- 説明文
- HTML カタログ
- モデル
- 設定
- ログ
- **途中で止めた動画の中間ファイル**（次回の再開に必要なため必ず残ります）

### ゴミ箱へ移動できなかったと出る

ファイルは**そのまま残しています**。完全削除へ切り替えることはしません。
ファイルを開いているアプリを閉じてから、もう一度実行してください。
