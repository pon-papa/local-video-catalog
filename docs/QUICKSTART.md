# はじめかた（最初の 1 本を解析する）

この文書のとおりに進めると、**動画 1 本を解析して HTML カタログに載せる**
ところまで到達できます。所要 5〜10 分（動画の長さと PC の性能によります）。

いきなり大量に処理しないでください。**まず 1 本**が確実に通ることを
確かめてから増やすほうが、うまくいかなかったときに原因が分かります。

---

## 1. 展開する

ZIP を、**書き込みできる場所**へ展開します。

```
例: C:\Users\<あなた>\Documents\local-video-catalog\
```

`Program Files` の下は書き込みが制限されることがあるので避けてください。
フォルダー名に日本語や空白が入っていても動きます。

Python のインストールは不要です（アプリの中に同梱しています）。

---

## 2. ffmpeg と ffprobe を用意する

動画の情報を読み、代表画像を取り出すために使います。

<https://ffmpeg.org/download.html> から Windows 向けのビルドを入手し、
展開した場所を覚えておいてください（`bin\ffmpeg.exe` と `bin\ffprobe.exe`）。

> **文字起こしも使いたい場合**
> `whisper` フィルターを含むビルド（8.x 以降のフル版）が必要です。
> 使わない場合は、後の画面で「文字起こしを飛ばす」にチェックを入れれば
> そのまま進められます。

---

## 3. LM Studio を用意する

映像の内容を読み取るローカル AI です。**これは必須**です。

1. <https://lmstudio.ai/> から入手して起動します
2. モデル検索で **`qwen3-vl-8b-instruct`** を取得します
   （このアプリで動作を確認しているモデルです）
3. そのモデルを読み込みます
4. **Local Server を ON** にします（既定では `http://127.0.0.1:1234`）

映像を外部へ送ることはありません。接続先は同じ PC の中だけです。

---

## 4. 文字起こしを使う場合だけ: Whisper モデルを置く

<https://huggingface.co/ggerganov/whisper.cpp> から `ggml-*.bin` を入手し、
展開したフォルダーの中の

```
userdata\models\whisper\
```

へ置きます。動作を確認しているのは `ggml-large-v3-turbo-q5_0.bin` です。

---

## 5. 起動する

**`Start.cmd` をダブルクリック**します。

画面が開くと、自動で環境チェックが走ります。

---

## 6. 環境チェックを緑にする

次のように出れば準備完了です。

```
✓ ffmpeg        ...
✓ ffprobe       ...
✓ ローカルAI     接続済み（n モデル）
✓ 使用モデル     qwen3-vl-8b-instruct（動作確認済み）
✓ 画像入力       対応しています
✓ 解析を開始できます。
```

**✕ が出たら、その行に書かれた対処をそのまま行ってください。**

よくあるのは次の 2 つです。

- `✕ 使用モデル 未選択`
  → 「今回の実行条件」の **「設定…」** を押し、映像の解析に使うモデルを選びます
- `✕ ffmpeg を利用できません`
  → 「参照」から `ffmpeg.exe` の場所を指定します

「画像入力」の確認では、アプリがその場で作った 8×8 のテスト画像を 1 枚だけ
LM Studio へ送ります。動画やあなたのデータは送りません。

---

## 7. 最初の 1 本を解析する

「今回の実行条件」を次のようにします。

| 項目 | 最初のおすすめ |
|---|---|
| 稼働時間 | 時間制限なし |
| 処理する本数 | **1** |
| 文字起こしを飛ばす | 使わないならチェックを入れる |
| 完了した動画の中間ファイルをゴミ箱へ移動する | **チェックを外す** |

最初は中間ファイルを残しておくと、うまくいかなかったときに確かめられます。

1. 「入力元」の **「参照…」** で動画の入ったフォルダーを選びます
2. **「対象確認」** を押します。これから何をするか、どの動画を選んだかが出ます
3. よければ **「処理開始」** を押します

---

## 8. 終わったら見る

ログの最後に、こう出れば成功です。

```
説明文を作成しました（local-llm）: <台帳ID>_<動画のファイル名>.txt

HTMLカタログを更新しました: ...\userdata\catalog\catalog.html
1 件

完了した動画 : 1 本（着手 1 / 対象 1 本）
失敗         : 0 件
```

**「HTMLカタログを開く」** を押すと、ブラウザーで一覧が開きます。
検索・絞り込みができます。

説明文そのものを読みたいときは **「説明文を開く」** を押します。

---

## 9. うまくいったら増やす

1 本が通ったら、本数や稼働時間を増やしてください。

- 途中で止めたくなったら **「安全停止」**。区切りのよいところで止まり、
  次回は続きから始まります
- 「稼働時間」を決めておくと、その時間で自動的に区切ります
- 中間ファイルが増えてきたら「完了した動画の中間ファイルを
  ゴミ箱へ移動する」にチェックを入れて実行します

処理にかかる時間は、動画の長さ・PC の性能・GPU の有無で**大きく変わります**。
