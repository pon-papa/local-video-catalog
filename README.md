# Local Video Catalog

手元の動画を **このPCの中だけで** 解析して、内容の説明文と
検索できる HTML カタログを作る Windows 向けのツールです。

ホームビデオ、旅行やイベントの記録、趣味・研究・業務の映像など、
「撮ったけれど中身を覚えていない動画」を探せるようにします。

**v0.9.0-beta（公開 beta）**

- 動画・画像・音声・文字起こし・説明文を **外部へ送信しません**
- 解析は同じ PC 上の LM Studio と ffmpeg だけで行います
- **元の動画は読むだけ**です。書き換え・改名・移動・削除をしません
- アプリが作るものは、すべてこのフォルダーの中に置きます

---

## まず使う

くわしい手順は **[docs/QUICKSTART.md](docs/QUICKSTART.md)** にあります（5〜10 分）。
ここでは流れだけ示します。

1. ZIP を、書き込みできる場所へ展開する
2. **ffmpeg / ffprobe** を用意する
3. **LM Studio** を用意する
4. LM Studio で **VLM モデル**（例: `qwen3-vl-8b-instruct`）を読み込む
5. LM Studio の **Local Server を ON** にする
6. **`Start.cmd` をダブルクリック**
7. 画面の**環境チェック**に従って、足りないものを揃える
8. 動画の入ったフォルダーを選ぶ
9. **「対象確認」**で、何をするか・どの動画かを確かめる
10. **「処理開始」**（最初は 1 本だけをおすすめします）
11. **「HTMLカタログを開く」**で結果を見る

> **Python と文字起こしモデルの用意は不要です。**
> 実行に必要な Python は `runtime\` に、文字起こしモデルは
> `userdata\models\whisper\` に、それぞれ**最初から入っています**。
> お使いの PC の Python 環境には触れません。

## 別途ご用意いただくもの

サイズ・ライセンス・更新頻度の都合で、次は同梱していません。

| 必要なもの | 用途 | 必須か |
|---|---|---|
| Windows 10 / 11（64bit） | 動作環境 | 必須 |
| [LM Studio](https://lmstudio.ai/) | 映像の解析・説明文の生成 | **必須** |
| VLM モデル（動作確認済み: `qwen3-vl-8b-instruct`） | 映像の解析 | **必須** |
| [ffmpeg / ffprobe](https://ffmpeg.org/download.html) | 動画情報の取得・静止画の抽出 | **必須** |
| whisper フィルター入りの ffmpeg（8.x 以降のフル版） | 文字起こし | 文字起こしを使う場合 |

ffmpeg と ffprobe は**同じフォルダーにあれば片方を指定するだけ**で、
もう片方も自動で見つけます（通常の配布物は `bin\` に両方入っています）。

**文字起こしモデルは同梱済みです**（`ggml-large-v3-turbo-q5_0.bin`）。
ご自身で用意する必要はありません。別のモデルを使いたい場合は
「ローカルAI設定」で選べます（`userdata\models\whisper\` に置いたもの）。

**文字起こしは任意です。** whisper フィルター入りの ffmpeg が無い場合は、
画面の「文字起こしを飛ばす」にチェックを入れれば、そのほかの工程は進められます。
**チェックを入れない限り、文字起こしを黙って省くことはありません。**

**映像の解析は必ず行う工程です。** このツールの中心なので、飛ばす設定はありません。
そのため、LM Studio が起動しているだけでは処理を開始できません。
次の 4 つが揃ってはじめて「処理開始」が押せるようになります。

1. LM Studio へ接続できる
2. 映像の解析に使うモデルが**選択されている**
3. 選んだモデルが今も利用できる
4. そのモデルが**実際に画像入力を処理できた**

4 の確認では、アプリがその場で作った 8×8 の小さなテスト画像を 1 枚だけ
LM Studio へ送ります。**動画・代表画像・あなたのデータは一切送りません。**
モデル名に `VL` や `Vision` が入っているかどうかでは判断しません
（名前が合っていても画像を扱えないモデルがあるためです）。

処理にかかる時間は、動画の長さ・PC の性能・GPU の有無で**大きく変わります**。

## できること

1. 動画フォルダーを指定して解析する
2. 動画の登録と基本情報の取得（ffprobe）
3. 代表静止画の抽出
4. ローカル VLM による映像内容の解析と全体の視覚概要
5. ローカル Whisper による文字起こし
6. 動画 1 本ごとの説明文を作る（YouTube 概要欄用の短文つき）
7. 検索・絞り込みできる HTML カタログを作る（**解析のたびに自動で更新**）
8. **途中で安全に停止し、次回は続きから再開する**
9. 失敗した動画だけをやり直す
10. 完了した動画の中間ファイルを Windows のゴミ箱へ整理する

大量の動画を一晩で終わらせる前提にしていません。
**停止 → 確認 → 再開**を繰り返す運用を想定しています。

稼働時間や「安全停止」で途中終了しても、**それは失敗ではありません。**
そこまでの成果は保存され、次回は続きから始まります。画面には
「完了した動画」「途中まで処理」「失敗」が分けて表示されます。

## 保存先について

このツールが作るものは、**すべてこのフォルダーの `userdata\` の中**にあります。
`%LOCALAPPDATA%` やレジストリなど、見えない場所へは何も書きません。

| したいこと | やること |
|---|---|
| バックアップ | このフォルダーをコピーする |
| 別の PC へ移す | このフォルダーを移動する |
| 別の動画群を管理する | このフォルダーごとコピーして別環境として使う |
| やめる | このフォルダーを削除する |

**1 フォルダー = 1 解析環境**です。

## 安全に関する設計

| 項目 | 方針 |
|---|---|
| 元動画 | 読み取り専用でしか開きません。生成物を元動画のフォルダーへ書きません |
| 外部送信 | 接続先を `127.0.0.1` / `localhost` / `::1` に限定し、HTTP リダイレクトを辿らず、プロキシ環境変数を無効化します。「外部を許可する」オプションを実装していません |
| 中間ファイルの整理 | このフォルダーの `userdata\cache\` の中だけが対象です。完全削除はせず、Windows のゴミ箱へ送ります。送れなければファイルを残します |
| 整理の対象 | **最後の工程まで終わった動画だけ**です。途中で止めた動画の中間成果は、次回の再開に必要なので必ず残ります |
| 保護されるもの | 元動画・台帳・最終説明文・HTML カタログ・モデル・ログ・設定 |
| AI の推定 | 人物名・人間関係・場所・行事などを根拠なく断定しません |
| 文字起こしの幻覚 | 「ご視聴ありがとうございました」等の既知の定型は印を付けて保存し、**説明文の材料からだけ除外**します。元の記録は消しません |

## 開発者向け

配布物を使うだけなら、ここから先は読む必要はありません。

```bash
python -m pytest tests -q
```

```bash
python tools/privacy_guard.py
```

配布 ZIP の作り方（`runtime\` の素材は python.org 公式からのみ取得し、
`tools/runtime_sources.json` に版・取得元・SHA-256 を記録しています）:

```bash
python tools/build_runtime.py --sources <素材の置き場>
```

```bash
python tools/make_release.py
```

設計文書は `docs/CURRENT_SYSTEM_AUDIT.md` / `docs/PORTABLE_V1_DESIGN.md` /
`docs/MIGRATION_PLAN.md` / `docs/GUI_FEATURE_PARITY.md` / `docs/PYTHON_RUNTIME.md`
にあります（**配布 ZIP には入れていません**。読む相手が違うためです）。
