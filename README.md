# local-video-catalog

手元の動画を **ローカル AI だけで** 解析し、内容の説明文と検索できる HTML カタログを作る
Windows 向けツールです。

- 動画・画像・音声・文字起こしの内容を **外部クラウドへ送信しません**
- 解析は同じ PC 上の LM Studio（localhost）と ffmpeg 内蔵 whisper だけで行います
- **元動画は読み取り専用**です。上書き・改名・移動・削除・メタデータ書換えをしません
- ホームビデオ / 旅行記録 / イベント / スポーツ / 趣味 / 研究記録 / 業務記録 /
  過去の映像アーカイブなど、**動画の種類を限定しません**

> **現在の状態: 設計フェーズ（Phase 0 完了）**
> 調査・設計・移植計画までが完了しています。アプリ本体はこれから実装します。
> 実装計画は [docs/MIGRATION_PLAN.md](docs/MIGRATION_PLAN.md) を参照してください。

## One-Folder 完結

このツールが生成・保持するデータは、**すべてこのフォルダーの `userdata\` の中**にあります。
`%LOCALAPPDATA%` やレジストリなど、見えない場所へは何も書きません。

| したいこと | やること |
|---|---|
| 使う | このフォルダーを開く |
| バックアップ | このフォルダーをコピーする |
| 別の PC へ移す | このフォルダーを移動する |
| 別の動画群を管理する | このフォルダーごとコピーして別環境として使う |
| やめる | このフォルダーを削除する |

**1 フォルダー = 1 解析環境**です。

```
local-video-catalog\              ← APP_ROOT
├─ app-root.marker                 ここがアプリの根であることの目印
├─ Start.cmd                       ダブルクリックで起動
├─ src\local_video_catalog\        アプリ本体
├─ config\settings.example.json    設定のサンプル
├─ tools\                          保守用スクリプト
├─ tests\                          自動テスト
├─ docs\                           設計文書
└─ userdata\                       ★ 実行時に作られるものはすべてここ
    ├─ config\                      設定・画面状態
    ├─ catalog\                     台帳（SQLite）・HTML カタログ・エクスポート
    ├─ descriptions\                最終説明文
    ├─ cache\                       解析の中間結果
    ├─ models\whisper\              文字起こしモデル（自分で置きます）
    ├─ logs\  runs\  temp\
    └─ control\                     安全停止の要求ファイル
```

## 必要なもの（自動インストールはしません）

このツールは外部ソフトを勝手にダウンロード・インストールしません。
起動後の「環境チェック」で、**見つかったか / 何が足りないか / 何を用意すればよいか**を表示します。

| 必要なもの | 用途 | 備考 |
|---|---|---|
| Windows 10 / 11 | 動作環境 | |
| Python 3.13 以降 | アプリ本体 | サードパーティパッケージは不要 |
| ffmpeg / ffprobe（8.x 以降のフル版） | 動画情報の取得・静止画抽出・文字起こし | **whisper フィルターを含むビルドが必要** |
| LM Studio | 映像内容の解析と説明文の生成 | **必須。** ローカルサーバーを ON にして使います |
| VLM モデル | 映像内容の解析 | **必須。** 動作確認済み: `qwen3-vl-8b-instruct` |
| Whisper モデル（`ggml-*.bin`） | 文字起こし | 文字起こしを行う場合のみ。動作確認済み: `ggml-large-v3-turbo-q5_0.bin` |

VLM モデルと Whisper モデルは**同梱していません**。ご自身で用意して、
Whisper モデルは `userdata\models\whisper\` へ置いてください。

**映像の解析は必ず行う工程です。** このツールの中心なので、飛ばす設定はありません。
LM Studio と VLM モデルが使えないあいだは「処理開始」を押せません
（動画ライブラリの確認・HTMLカタログの閲覧・説明文の確認・設定変更はいつでもできます）。

**文字起こしは任意です。** whisper 対応の ffmpeg や Whisper モデルが無い場合は、
「文字起こしを飛ばす」にチェックを入れれば、そのほかの工程は進められます。

## できること（v1 の予定）

1. 動画フォルダーを指定して解析を開始する
2. 動画の登録と基本情報の取得（ffprobe）
3. 代表静止画の抽出
4. ローカル VLM による映像内容の解析と全体の視覚概要
5. ローカル Whisper による文字起こし
6. 解析結果から動画 1 本ごとの説明文を作る（YouTube 概要欄用の短文つき）
7. 説明文から検索・絞り込みできる HTML カタログを作る
8. **途中で安全に停止し、次回は続きから再開する**
9. 失敗した動画だけをやり直す
10. 正常に完了した動画の中間ファイルを Windows のゴミ箱へ整理する

大量の動画を一晩で終わらせる前提にしていません。
**停止 → 確認 → 再開**を繰り返す運用を想定しています。

### 「処理する本数」の意味

本数の指定は、**映像の解析・文字起こし・説明文の作成まで進める動画の数**です。

動画フォルダーの一覧確認（どんな動画が何本あるかを調べる作業）は、
本数の指定にかかわらず毎回フォルダー全体に対して行います。
一度確認した動画は次回からすぐ終わるので、時間がかかるのは最初だけです。

> 例: 329 本入ったフォルダーで「3 本」と指定した場合
>
> - 329 本すべての一覧を確認します（時間・再生時間・音声の有無など）
> - そのうち **3 本だけ**を解析して説明文を作ります

### どの動画が選ばれるか

**まだ解析が終わっていない動画を、台帳ID（VID-000001…）の小さい順に、
指定した本数だけ**選びます。台帳IDはフォルダー名・ファイル名の昇順で
振られるため、**同じフォルダー・同じ状態なら何度実行しても同じ順番**です。

「対象確認」を押すと、実行前に次が分かります。

- 動画ライブラリの総数
- 今回の上限と、実際に解析する本数
- 選び方
- 選ばれた動画の一覧と、**それぞれが選ばれた理由**

途中で停止した動画は「前回どこまで終わったか」、失敗のみ再試行では
「前回どの工程でうまくいかなかったか」が理由として表示されます。

> HTMLカタログの「古い順」などの並び替えは**表示の都合**であり、
> 処理する順番とは関係ありません。

## 安全に関する設計

| 項目 | 方針 |
|---|---|
| 元動画 | 読み取り専用でしか開きません。生成物を元動画のフォルダーへ書きません |
| 外部送信 | 接続先を `127.0.0.1` / `localhost` / `::1` に限定し、HTTP リダイレクトを辿らず、プロキシ環境変数を無効化します。「外部を許可する」オプションを実装していません |
| 中間ファイルの整理 | このフォルダーの `userdata\cache\` の中だけが対象です。**設定が壊れていてもフォルダーの外へは出ません**。完全削除はせず、Windows のゴミ箱へ送ります。送れなければファイルを残します |
| 保護されるもの | 元動画・台帳・最終説明文・HTML カタログ・モデル・ログ |
| Resume | 完了した工程は台帳に記録され、再開時に飛ばされます |
| AI の推定 | 人物名・人間関係・場所・行事などを根拠なく断定しません。AI の推定と、利用者が確認した事実を区別して扱います |
| 文字起こしの幻覚 | 「ご視聴ありがとうございました」等の既知の定型は疑いの印を付けて保存し、**説明文の材料からだけ除外**します。元の記録は消しません |

## 開発

このリポジトリは**開発・検証専用**です。実動画を使う運用は、
配布物一式を別フォルダーへコピーして行ってください。

```bash
python -m unittest discover -s tests -p "test_*.py"
```

```bash
python tools/privacy_guard.py
```

`privacy_guard.py` は、実データや個人環境の絶対パスが Git へ混入していないかを検査します。
**commit の前に必ず実行してください。** CI でも同じ検査が走ります。
